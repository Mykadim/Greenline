# Greenline HSE Static Site

This folder contains a runnable one-page website built from the Greenline HSE white paper.

## Run it

Open `index.html` in your browser, or run:

```powershell
.\run.ps1
```

If you have Python installed, you can also serve it locally from this folder:

```powershell
python -m http.server 5173
```

Then visit:

```text
http://localhost:5173
```

## Files

- `index.html` - page structure and content
- `styles.css` - brand styling and responsive layout
- `script.js` - mobile navigation, scroll reveals and stat counters
- `run.ps1` - opens the site in your default browser
- `assets/greenline-hero.png` - generated hero image
- `assets/greenline-motion.mp4` - hero motion background
- `Greenline-HSE-White-Paper.md` - developed source white paper
